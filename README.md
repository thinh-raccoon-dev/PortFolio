# PortFolio

Personal portfolio of **Lại Văn Thịnh** — cinematic dark/light theme built with Next.js, Framer Motion, GSAP, and Tailwind CSS.

## Features

- Prisma-inspired cream/black aesthetic
- English / Vietnamese language toggle
- Dark / light theme
- Smooth scroll, scroll-driven animations
- Project showcase with video & image cards

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
